# One-Slide Project Pitch

## AI-Powered Predictive Maintenance for IoT Devices

Problem: Industrial equipment failures cause unexpected downtime, production loss, and high repair costs.

Solution: I built an AI-driven predictive maintenance system that analyzes sensor data from machines and predicts failure risk before breakdowns occur.

What I did:
- Simulated realistic IoT sensor data for industrial equipment
- Cleaned and prepared the dataset for machine learning
- Engineered health-related features from sensor readings
- Trained a failure prediction model and evaluated it using key metrics
- Built an interactive Streamlit dashboard for monitoring risk levels

Impact:
- Reduced reactive maintenance dependence
- Improved readiness for proactive asset management
- Demonstrated skills in Python, ML, industrial analytics, and dashboarding

Tech stack: Python, Pandas, NumPy, Scikit-learn, Seaborn, Streamlit, Jupyter

This project shows how AI can turn raw machine data into actionable operational insight for smarter factories and industrial systems.
