# Project Showcase Slide Summary

## Title
AI-Powered Predictive Maintenance for IoT Devices

## Problem statement
Industrial machines often fail without warning, causing production downtime, expensive repairs, and lost efficiency. Traditional maintenance is reactive and expensive.

## Objective
Build a practical AI system to detect early signs of machine failure using sensor data and predict when maintenance is needed before a breakdown occurs.

## What I built
- Simulated industrial IoT sensor data
- Data cleaning and feature engineering pipeline
- Machine learning model for failure prediction
- Business alert generation for risky equipment
- Streamlit dashboard for interactive monitoring
- Model evaluation with accuracy, precision, recall, and F1 score

## Why this matters
This solution helps reduce downtime, improve reliability, and lower operational costs in manufacturing, energy, automotive, and aerospace environments.

## Tech stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Streamlit, Jupyter Notebook

## Key outcome
The project demonstrates an end-to-end predictive maintenance workflow and shows how AI can support real industrial decision-making.

## Final pitch
I built an AI-powered maintenance intelligence system that turns raw sensor data into actionable alerts, helping organizations shift from reactive repair to proactive asset management.
